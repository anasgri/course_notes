Transitions and animations

Below is the example of the animated button


.button {
    background-color: blue;
    transition: background-color 1s ease;
}
.button:hover {
    background-color: green;
}

The actual syntaxis of the transition.

transition: property duration timing function delay

Example:


transition: all 0.5s ease-in-out 0s;
  • all = what properties to animate
  • 0.5s = how long it lasts
  • ease-in-out = speed curve
  • 0s = delay before starting

      button {
        background-color: blue;
        transition: all 1s ease 0s;
      }

      button:hover {
        background-color: green;
        transform: scale(1.2);
      }

Different timing functios

You can transition changes in:

  • Colors (background-color, color)
  • Position (left, top)
  • Size (width, height)
  • Opacity
  • Transform (scale, rotate)

Css animations

  • @keyframes define stages of the animation
  • animation property controls timing and behaviour

@keyframes fadeIn {
  0% { opacity: 0; }
  100% { opacity: 1; }
}
.box {
  animation: fadeIn 1s ease-in-out forwards;
}

Animation synatax

animation: name duration timing-function delay iteration-count direction fill-mode;

Example:


      animation: bounce 1s ease 0s infinite alternate both
  • bounce = name of the keyframe animation
  • 1s = duration of the animation
  • ease = timing function (speed curve)
  • 0s = delay before starting
  • infinite = number of times it repeats
  • alternate = direction of the animation (reverses every cycle)
  • both = fill mode (retains styles before and after animation)
