Lazy loading

Lazy loading means delaying the loading of resources (like images) until they’re needed, typically when they appear on screen. 


        <img src = "photo.jpg" loading="lazy" alt = "A scienic view">
  • Use modern formats like .webp or .avif
  • Compress images using tools like TinyPNG
  • Resize images to the max display size
  • Always add width/height attributes to avoid layout shifts

Minifying your CSS

  • Minifying = removing spaces, comments, and extra characters
  • Reduces file size and speeds up loading
  • Use tools like CSSNano or online compressors

        /* Original */
body {
  background-color: white;
}
/* Minified */
body{background-color:#fff}

Load CSS efficiently

  • Place <link> to your stylesheet in the >head<
  • Avoid using @import inside CSS files — it's slower
  • Consider splitting CSS for large projects: critical styles first, the rest later

Use tools like:

  • Google Lighthouse
  • PageSpeed Insights
  • WebPageTest

These tools give tips for improving speed and performance.
