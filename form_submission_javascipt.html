Asynschronous form submission

Recap on the formData

If HTML form element is provided, it automatically captures its fields.

The special thing about FormData is that network methods, such as fetch, can accept a FormData object as a body. It’s encoded and sent out with Content-Type: multipart/form-data.

From the server point of view, that looks like a usual form submission. 


  let formData = new FormData(form); // formdata object
  form.addEventListener("submit", function(event) {
  event.preventDefault();
  let formData = new FormData(form);
  // acessing the indivisula values using formData.get
  console.log(formData.get("name"));
  console.log(formData.get("email"));
  console.log(formData.get("message"));
});

The formData stores the inputs as key value pairs.

The key value pairs can be acessed by their kets that are specified by the name tag in the form 


    
  <input type="email" name="email" placeholder="Email" required>

// This is the function for the data validation. Will be used later. 
// .trim() is equivalent to python .strip(), removes extra spaces. 
function validateForm(formData) {
  let name = formData.get('name').trim()
  let email = formData.get('email').trim()
  let message = formData.get('message').trim()

  if (name === '' || email === '' || message === '') {
    alert('All fields are required!')
    return false
  }

  return true
}
