Interactivity and DOM (document object model)

DOM: Represents the HTML document as objects and nodes that can be manipulated

Rendering a web page involves several steps:

  1. Parsing HTML: The browser parses HTML and creates the DOM.
  2. Parsing CSS: CSS rules are applied to corresponding elements.
  3. Constructing the Render Tree: Combines the DOM and CSS to determine how elements will appear.
  4. Layout: Calculates the exact position of each element.
  5. Painting: Renders the visual elements to the screen

DOM is created each time the page renders, the JavaScript modifies the DOM, not the original HTML.

JavaScript

  • getElementById() returns a single element.
  • querySelector() returns the first matching element.
  • querySelectorAll() returns a NodeList of all matching elements.

You can also grab a container and point at its child or parent elements. 


let parent = document.getElementById("content").parentNode; // points to the parent element
let children = document.getElementById("content").children; // points to the children of the selected container
let firstChild = document.getElementById("content").firstElementChild; // selects first child element
let firstChild = document.getElementById("content").lastElementChild; // selects the last child element

After you get the element, you can save the element in the variable.

And then manipulate the element.

.innerText - modifies a text

.createElement(); - creates a new element and adds it to DOM

.appendChild(); adds element to the DOM

.remove();- removes an element.

The .createElement() method creates a new element based on the specified tag name passed into it as an argument. However, it does not append it to the document. It creates an empty element with no inner HTML.

You have to use .appendChild() to add it.


  // Change content
let heading = document.getElementById("title");
heading.innerText = "New Title";

// Create a new element
let newPara = document.createElement("p");
newPara.innerText = "This is a new paragraph.";
document.body.appendChild(newPara);

// Remove an element
let item = document.getElementById("item1");
item.remove();

You can assign id to the newly created element


let newAttraction = document.createElement('li');
newAttraction.id = 'vespa';

Remove an Element

In addition to modifying or creating an element from scratch, the DOM also allows for the removal of an element. The .removeChild() method removes a specified child from a parent. 

let paragraph = document.querySelector('p');
document.body.removeChild(paragraph);

In the above example code, the .querySelector() method returns the first paragraph in the document. Then, the paragraph element is passed as an argument of the .removeChild() method chained to the parent of the paragraph— document.body. This removes the first paragraph from the document body.

If you want to hide an element rather than completely deleting it, the .hidden property allows you to hide it by setting the property as true or false: 

document.getElementById('sign').hidden = true;

Add Click Interactivity

You can add interactivity to DOM elements by assigning a function to run based on an event. Events can include anything from a click to a user mousing over an element.

The .onclick property allows you to assign a function to run on when a click event happens on an element: 

let element = document.querySelector('button');

element.onclick = function() {
  element.style.backgroundColor = 'blue'
};

You can also assign the .onclick property to a function by name: 

let element = document.querySelector('button');

function turnBlue() {
   element.style.backgroundColor = 'blue';
}

element.onclick = turnBlue;

You can also include Event listeners to buttons


  let button = document.getElementById("btn");
button.addEventListener("click", function() {
  alert("Button clicked!");
});
