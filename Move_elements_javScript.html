Creating and Removing Elements Dynamically

createElement() creates a new DOM element.


    let newPara = document.createElement("p");
    newPara.innerText = "This is a new paragraph.";
  • createElement() creates an element but does not add it to the DOM.
  • Use innerText or innerHTML to set content, even if you do it it still not added to the DOM

Adding Elements to the DOM

To add elements to the DOM, use appendChild() or insertBefore(). 


        // Select parent element
let container = document.getElementById("container");

// Add element to the end
container.appendChild(newPara);

// Insert before another element
let reference = document.getElementById("reference");
container.insertBefore(newPara, reference);
  • appendChild() adds the element at the end.
  • insertBefore() adds the element before a reference element
  • append() can add multiple elements or text at once

let div = document.createElement("div");
div.innerText = "I am a div";
let span = document.createElement("span");
span.innerText = "I am a span";

// Add multiple elements
document.body.append(div, span);

Setting attribute dynamically

Use setAttribute() to add or modify attributes.


    let link = document.createElement("a");
link.innerText = "Visit Website";
link.setAttribute("href", "https://www.example.com");
link.setAttribute("target", "_blank");
document.body.appendChild(link);
  • setAttribute() adds or modifies attributes dynamically.
  • Useful for adding links, classes, or other attributes

Removing elements from the DOM

The remove() method deletes an element from the DOM.


let para = document.getElementById("para");
para.remove();

Removing Child Elements with removeChild()

To remove a specific child element, use removeChild()


let parent = document.getElementById("container");
let child = document.getElementById("item");
parent.removeChild(child);
  • removeChild() removes a child node from its parent.
  • Use when you need to remove a specific element.

Replace the element with the new one

replaceChild() replaces an existing element with a new one 


        let parent = document.getElementById("container");
let oldChild = document.getElementById("old");
let newChild = document.createElement("div");
newChild.innerText = "This is a new element.";

parent.replaceChild(newChild, oldChild);

Below is the example how you can create and remove multiple elements using the loop. 


        // Create multiple elements
for (let i = 0; i < 5; i++) {
  let item = document.createElement("li");
  item.innerText = `Item ${i + 1}`;
  document.getElementById("list").appendChild(item);
}

// Remove all items
let list = document.getElementById("list");
while (list.firstChild) {
  list.removeChild(list.firstChild);
}
