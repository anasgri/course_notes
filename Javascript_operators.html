JavaScript operators

Arithmetic Operators


let a = 10, b = 3;

console.log(a + b);   // 13  → Addition
console.log(a - b);   // 7   → Subtraction
console.log(a * b);   // 30  → Multiplication
console.log(a / b);   // 3.333... → Division
console.log(a % b);   // 1   → Modulus (remainder)
console.log(a ** b);  // 1000 → Exponentiation

let c = 5;
console.log(c++);  // 5 (then c becomes 6) → Increment
console.log(c--);  // 6 (then c becomes 5) → Decrement

Assignment Operators


let x = 10;
x += 5;   // x = x + 5  → x is now 15
x -= 3;   // x = x - 3  → x is now 12
x *= 2;   // x = x * 2  → x is now 24
x /= 4;   // x = x / 4  → x is now 6
x %= 4;   // x = x % 4  → x is now 2
x **= 3;  // x = x ** 3 → x is now 8

Comparison Operators


let m = 5, n = "5";
console.log(m == n);   // true  → Equal (loose, checks value only)
console.log(m === n);  // false → Strict equal (checks value + type)
console.log(m != n);   // false → Not equal
console.log(m !== n);  // true  → Strict not equal
console.log(m > 3);    // true  → Greater than
console.log(m < 3);    // false → Less than
console.log(m >= 5);   // true  → Greater than or equal
console.log(m <= 4);   // false → Less than or equal

Logical Operators


let age = 25;
let hasID = true;

console.log(age >= 18 && hasID);   // true  → AND (both must be true)
console.log(age < 18 || hasID);    // true  → OR (at least one true)
console.log(!hasID);               // false → NOT (flips the boolean)

Some aspects of the operators

If you type to the console 23 + "2" the result is going to be "232" of type string.

If you type 23 - "2" you get 21 of type number.

"23" - "2" will yield 21 of type number

"Hello " + "World" will yield Hello World

"Hello " - "World" will result in the error.
