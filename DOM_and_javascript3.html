Adding the event listeners to the page

Click event


let button = document.getElementById("myButton");
button.addEventListener("click", function() {
  alert("Button clicked!");
});

Below is the example with the arrow function.


    let btn = document.getElementById("btn");
btn.addEventListener("click", () => {
  console.log("Button was clicked!");
});

The code below can be used to make a button that changes the colour of the background 


      const button = document.querySelector("button");
      button.addEventListener("click", function (e) {
        console.log("You clicked me");
        if (document.body.style.backgroundColor === "blue") {
          document.body.style.backgroundColor = "white";
        } else {
          document.body.style.backgroundColor = "blue";
        }
      });

Keydown event


document.addEventListener("keydown", function(event) {
console.log(`Key pressed: ${event.key}`);
});

The example above saves the keys that the user presses.

Below is the example of the html document with the element moving up and down 


    <!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>keydown demo</title>
    <style>
      .character {
        width: 200px;
        height: 100px;
        position: relative;
        top: 100px;
        background-color: blue;
        border-radius: 100px;
      }
    </style>
  </head>
  <body>
    <h1>Keydown demo</h1>
    <div class="character" id="main"></div>
    <script>
      document.addEventListener("keydown", function (event) {
        if (event.key === "ArrowDown") {
          let char = document.getElementById("main");
          let currentTop = parseInt(char.style.top) || 0; // convert "10px" -> 10
          char.style.top = currentTop + 10 + "px"; // move down by 10px
        } else if (event.key === "ArrowUp") {
          let char = document.getElementById("main");
          let currentTop = parseInt(char.style.top) || 0; // convert "10px" -> 10
          char.style.top = currentTop - 10 + "px"; // move down by 10px
        }
      });
    </script>
  </body>
</html>

Mouseover events


let box = document.getElementById("box");
box.addEventListener("mouseover", () => {
  box.style.backgroundColor = "lightblue";
});
  • Can be used to change styles dynamically.
  • Ideal for creating hover effects

Input events


    let inputField = document.getElementById("name");
inputField.addEventListener("input", function(event) {
  console.log(`Current value: ${event.target.value}`);
});
  • Captures user input in real time.
  • Useful for form validation and live updates

Event object and properties


        let btn = document.getElementById("btn");
btn.addEventListener("click", function(event) {
  console.log(event.type);     // "click"
  console.log(event.target.id); // "btn"
});
  • event.type – Type of event.
  • event.target – The element that triggered the event

this and the event handling

Inside an event handler, this refers to the element that received the event. 


let button = document.getElementById("myButton");
button.addEventListener("click", function() {
  console.log(this.innerText);
});
  • Arrow functions do not bind this.
  • Use regular functions when you need this to refer to the target element.

Use removeEventListener() to detach an event listener

Example how do you remove the EventListener is shown below.


    function handleClick() {
  console.log("Button clicked");
}

let btn = document.getElementById("btn");
btn.addEventListener("click", handleClick);

// Remove the event listener
btn.removeEventListener("click", handleClick);
