Link example

Link can have a target attribute that will define whether the link is going to open in the new page when clicked or not

If the target is set to "_blank", the link will open in the new page


	<a href="https://www.w3schools.com" target = "_blank"> Link example </a>

Other variants of the tags include

  • _self - Opens the linked document in the same frame as it was clicked (this is default)
  • _blank - Opens the linked document in a new window or tab
  • _parent - Opens the linked document in the parent frame
  • _top - Opens the linked document in the full body of the window

What all this means? in short there is a <iframe></iframe> tag

that can be used to embed the document into another document

if you add the target = "_parent" the link opens in parent iframe

if you add the target = "_top" the link opens in the first window that is parent to everything that is embedded

Relative and absolute paths when working with links

It is preferrred to you absoulte paths e.g


<a href = "about_us.html">Link to about us page</a>

If you are using the live server you can use relative path


<a href = "/about_us.html">Link to about us page</a>

If you want to specify the link to the file that is one directory upp, use the following syntaxis


<a href = "../about_us.html">Link to about us page</a>
