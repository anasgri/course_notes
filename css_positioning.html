CSS positioning

The possible values that positioning can take

  • static (default)
  • relative
  • absolute
  • fixed
  • sticky

If you use static positioning, the top, bottom, left and right properties do not have the effect.

If you use the relative positioning, the element moves relative it's original position. 


.box {
    position: relative;
    top: 20px;
    left: 10px;
}

In this case the box is going to move 20px down. The other elements will be not affected by its movement.

Absolute positioning

  • Removed from the normal document flow.
  • Positioned relative to the nearest positioned ancestor (anything with position: relative, absolute, or fixed).
  • In order to affect the positioning, the ancestor need to have the positioining specified.
  • If no such ancestor exists, it’s positioned relative to the <html> element (the page itself).
  • Other elements on the page will behave as if this element does not exist.
  • As we scroll, it stays positioned within the container it is assigned to.

Position fixed

Position fixed is fixed to the viewpoint, this means that the elements will move with the scrolling.

Is removed from the document flow.

Sticky position

An element with position: sticky; toggles between a relative and fixed position, depending on the scroll position.

Is not removed from the document flow.

A sticky element is positioned relative until a certain scroll position is reached - then it "sticks" in that place (like position:fixed).

Z index

Z index is the property that only works with positioned elements. The index values are the numbers. The higher the value is the more closer to the user the element is, the lower the number is, the more at the back the element is.

Controls stacking order of positioned elements. Higher z-index appears on top.

💡 Key Tip: Z-index only works on positioned elements!


.box {
position: relative;
top: 20px;
left: 10px;
z-index: 2;
}
