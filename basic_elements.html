HTML semantic tags

Structural Tags

  • <header>: For top sections like logos and navigation.
  • <nav>: For navigation menus.
  • <section>: For grouping related content.
  • <footer>: For bottom sections like contact info.

Content tags

  • <article>: For independent pieces of content.
  • <aside>: For sidebars or related info.
  • <figure> and <figcaption>: For images and captions.
  • <main>: For main content of the page.

Non-semantic tags

<div></div> tag

<div></div> tag is the non-semantic tag

It dividees the text into the sections, but does not have meaning


        <div>

span tag

Another non-semantic tag is span. It can be used to style the fraction of the text.


      <p>My mother has <span style="color:blue">blue</span> eyes.</p>

My mother has blue eyes.
