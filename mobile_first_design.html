Mobile first design

Media queries let you write CSS that only applies when the browser matches certain conditions.

This rule applies only when the screen is 600px wide or smaller:


        @media (max-width: 600px) {
  body {
    background-color: lightblue;
  }
}

Mobile-first means you start with styles for small screens, then add rules for larger screens as needed. Example: 


        /*Default mode */
        .container {
            padding: 1rem;

        }
        /*Larger screen */
        @media (min-width: 768px) {
            .container {
                padding: 2rem;
            }
        }

The CSS @media rule is used in media queries to apply different styles for different media types/devices.

You can use breakpoints to control layout changes across screen sizes:

  • 576px: small devices
  • 768px: tablets
  • 992px: desktops
  • 1200px: large desktops
