Pseudo elements and pseudo classes

Pseudo-elements and pseudo-classes let you style parts of an element or apply styles based on state or structure. These are powerful tools for adding interactivity and polish without changing your HTML.

Common psudoclasses

  • :hover – when the mouse is over an element
  • :active – when the element is being clicked
  • :focus – when the element is focused (e.g., input field)
  • :nth-child() – targets elements by their position in a list
  • :first-child, :last-child – first or last child of a parent

Pseudoclass

A pseudo-element lets you style a specific part of an element

  • Common pseudo-elements: ::before – inserts content before an element
  • ::after – inserts content after an element
  • ::first-line – targets the first line of text
  • ::first-letter – targets the first letter of text

In the example below the first line will be made bold


        p::first-line {
            font-weight: bold;
        }

::before and ::after

These are often used to add decorative content:

content is required to make ::before and ::after visible.

You can style them like any other element


.card::before {
  content: "★ ";
  color: gold;
}

.card::after {
  content: " ✨";
  color: lightblue;
}
