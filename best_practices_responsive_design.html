Best Practices for Responsive Design with Bootstrap

Bootstrap is built mobile-first. That means: Your styles apply to small screens by default.

You add classes to adjust layout on small (sm), medium (md), large (lg), extra-large (xl), extra-extra-large (xxl) screens.

Responsive design means your website looks good on any screen, from phones to large desktops. Bootstrap makes this easier with mobile-first classes and a flexible grid system

  • Always wrap rows inside a .container or .container-fluid.
  • Combine .row and .col-* classes to structure content.
  • Use breakpoints (col-sm, col-md, col-lg, etc.) to change layouts based on screen size

You can change how columns are displayed on each screen size. In this example, on mobile, the columns stack. On tablets and desktops, they appear side-by-side 


<div class="row">
<div class="col-12 col-md-6">Left (stacks on small screens)</div>
<div class="col-12 col-md-6">Right</div>
</div>

Typography and padding

Make more padding on larger screens.

Use heading classes (h1, h2, etc.) instead of resizing manually


        <div class="p-3 p-md-5">More padding on medium+ screens</div>

Avoid fixed widths

Instead of setting a fixed width with CSS, use Bootstrap width classes or percentages. This keeps your layout flexible 


    <div class = "w-100 w-md-75">

Always test your design at different screen sizes:

  • Resize your browser.
  • Use browser dev tools.
  • Use a Bootstrap extension in your browser.
  • Preview on a real phone when possible.
