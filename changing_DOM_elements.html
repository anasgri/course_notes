Changing DOM Elements

Overall syntax for changing DOM elements in JavaScript:


        myElement.setAttribute("attributeName", "newValue");

Example:


        let myElement = document.getElementById("myElement");
        myElement.setAttribute("src", "newImage.jpg");

Changing the style

To change the style of an element, you can use the `style` property:


        let myElement = document.getElementById("myElement");
        myElement.style.color = "red";
        myElement.style.fontSize = "20px";

What to do with the attributes that have dashes

JavaScript can not include dashes in attribute names, so you need to use the `setAttribute` method with the attribute name in camelCase:

so attribute like font-family would be fontFamily


        // Single element
document.querySelector('.my-text').style.fontFamily = 'Verdana, sans-serif';

// Multiple elements
document.querySelectorAll('p').forEach(el => {
  el.style.fontFamily = 'Roboto, sans-serif';
});

Creating the element and adding it to the DOM


        // 1. Create the element
const newDiv = document.createElement('div');

// 2. Add content/attributes
newDiv.textContent = 'Hello, I am a new element!';
newDiv.className = 'my-new-class';
newDiv.setAttribute('id', 'greeting');
newDiv.style.fontFamily = 'Arial, sans-serif';
newDiv.style.color = 'blue';

// 3. Add it to the DOM
document.body.appendChild(newDiv);

Another way of adding text


var myListItem = document.createElement("li"); // create the new list item
var myTextNode = document.createTextNode("The Hobbit"); // create a text node with the content
myListItem.appendChild(myTextNode); // append the text node to the list item

var books = document.getElementById("books"); // get the reference to the existing list
books.appendChild(myListItem); // append the new list item to the existing list

insertBefore()

This is the alternative to the `appendChild()` method, that provides more control over where the element is inserted:

appendChild() adds the element as the last child of the parent node.

insertBefore() uses another element as a reference point for insertion. 


parent.insertBefore(newNode, referenceNode);


const list = document.getElementById('list'); // reference to the existing list
const newItem = document.createElement('li'); // create a new list item
newItem.textContent = 'Inserted second'; // adding the text content to the new list item
const secondItem = list.children[1]; // reference point
list.insertBefore(newItem, secondItem); // newItem goes right before secondItem
