The specificity hirerarchy (Highest to Lowest)

  1. 🏆 Inline Styles (Score: 1-0-0-0) – Applied directly inside the HTML tag using style="".
  2. ID Selectors 👑 (Score: 0-1-0-0) – Targets a unique element using a hashtag, like #nav or #header.
  3. Class, Attribute, and Pseudo-classes (Score: 0-0-1-0) – Includes classes like .nav, attributes like [type="text"], and states like :hover.
  4. Element (Type) and Pseudo-elements (Score: 0-0-0-1) – Targets raw HTML tags like div, p, or a.
  5. Universal Selector (Score: 0-0-0-0) – Matches everything using * but carries no specificity weigh.

Some common properties, that can be used to style text

  • color: sets the text color.
  • background-color: sets the background color.
  • font-size: defines the size of the text.
  • text-align: aligns text (left, center, right).
  • margin: space outside an element.
  • padding: space inside an element.
  • border: adds outlines to elements.

CSS can be added to HTML documents in 3 ways:

  • Inline - by using the style attribute inside HTML elements
  • Internal - by using a "style" element in the head section
  • External - by using a link element to link to an external CSS file

The examples of the inline CSS have been already covered


	<p style="color:red;">A red paragraph.</p>

A red paragraph.


Below is the example of the internal html


<!DOCTYPE html>
<html>
  <head>
    <style>
body {background-color: powderblue;}
h1   {color: blue;}
p    {color: red;}

</style>
  </head>
  <body>
    <h1>This is a heading</h1>
  </body>
</html>

In case of the external stylesheet , there is one document with html, that has extension .html

and another one with the css that has extension .css 

<!DOCTYPE html>
<html>
  <head>
    <link rel = "stylesheet" href = "styles.css">
  </head>
  <body>
    <h1>This is a heading</h1>
  </body>
</html>

Below is how the .css stylesheet should look like
