Music, audio and video

video file
</video>


<video>
<source src="ostrich_bald.mp4", type="video/mp4">
</video>

You can also specify the video height and width


<video src="myVideo.mp4" width="320" height="240" controls>
Video not supported
</video>

Different media formats are needed for compatibility with different browsers and devices. The <source> tag allows you to add multiple files. 

<video>
<source src="file.mp4" type="video/mp4">
<source src="file.webm" type="video/webm">
</video>

When different <source> options are included, the browser will choose the first one it supports.

You can add text between the <video> tags. The text will only be displayed in browsers that don’t support the video element. 


<video>
<source src="videofile.mp4" type="video/mp4">
<source src="videofile.webm" type="video/webm">
Video not supported
</video>

You can display play/pause, volume and other video controls with the controls attribute. 


<video controls>
<source src="ostrich_bald.mp4", type="video/mp4">
</video>

If you want to add external video or audio you can add it using the iframetag

Audio files

the way how audio files are embedded in the document is very similar to video 


<audio controls>
<source src="audiofile.mp3", type="audio/mpeg">
<source src="audiofile.ogg", type="audio/ogg">
Audio not supported
</audio>

You can also make audio or video to start as page loads. For that you should use autoplay attribute 


<audio autoplay>
<source src="audiofile.mp3", type="audio/mpeg">
<source src="audiofile.ogg", type="audio/ogg">
Audio not supported
</audio>

below is the exaample of the video that will start playing as file loads but will be muted 


<video autoplay muted>
<source src="videofile.mp4", type="video/mp4">
<source src="videofile.ogg", type="video/ogg">
</video>

below is the example of the audio that will loop


<audio loop>
<source src="audiofile.mp3", type="audio/mpeg">

</audio>
