Arrow functions

This is just the shorter syntaxis for writing functions.


      const multiply = (a, b) => {
        return a*b;
      };
      console.log(multiply(2, 4));

When the function has only one statement in its body, the {} brackers can be omitted. 


      const multiply = (a, b) => a*b;
      console.log( multiply(2, 3)); // 6

Deafult parameters

The defaulkt parameter, is what function uses when the user does not specify parameters when calling function. 


      function greet(name = "stranger") {
        console.log("Hello" + name);
      }
      greet(); // Hello stranger
      greet("Alice"); // Hello Alice

Rest parameters

Rest parameters is equivalent to **args in python


      function sum(...numbers) {
        return numbers.reduce((total, num) => total + num, 0);
      }
      console.log(sum(1, 2, 3, 4));

we use ...numbers when we are nut sure how many arguments there will be

The incoming value is the array.
