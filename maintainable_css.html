BEM convention

BEM stands for Block, Element, Modifier. A naming convention that makes CSS more readable and modular.

Example:


<div class="card card--highlight">
<h2 class="card__title">Title</h2>
<p class="card__description">Text</p>
</div>
  • card = Block (the standalone component)
  • card__title = Element (a part of the block)
  • card--highlight = Modifier (a variation of the block)

BEM best practices

  • Use double underscores __ for elements
  • Use double dashes -- for modifiers
  • Avoid deeply nested selectors
  • Be consistent with casing (e.g., all lowercase)
