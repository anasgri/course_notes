JavaScript Date Object


const now = new Date();
console.log(now);

Specifying the date and time:


const specificDate = new Date('2024-06-01');
console.log(specificDate);

The date calculates the milliseconds since January 1, 1970, 00:00:00 UTC. 


new Date(0)
// → Thu Jan 01 1970 00:00:00 GMT+0000 (epoch start)

new Date(1700000000000)
// → Tue Nov 14 2023 22:13:20 GMT+0000

new Date(-86400000)
// → Wed Dec 31 1969 00:00:00 GMT+0000 (negative = before epoch)

Creating date by supplying actual date values:


    new Date("2024-01-15")
// → Mon Jan 15 2024 00:00:00 GMT+0000 (ISO format, parsed as UTC midnight)

new Date("2024-01-15T10:30:00")
// → Mon Jan 15 2024 10:30:00 (local time)

new Date("January 15, 2024")
// → Mon Jan 15 2024 00:00:00 (local time)

new Date("01/15/2024")
// → Mon Jan 15 2024 00:00:00 (US format, local time)

new Date("not a date")
// → Invalid Date

Creating date by supplying components as numners


new Date(2024, 0, 15)
// → Mon Jan 15 2024 00:00:00 (month 0 = January!)

new Date(2024, 11, 25, 9, 30)
// → Wed Dec 25 2024 09:30:00

new Date(2024, 0)
// → Mon Jan 01 2024 00:00:00 (day defaults to 1)

new Date(2024, 13, 1)
// → Sat Feb 01 2025 00:00:00 (month 13 overflows into next year!)

new Date(2024, 0, 32)
// → Thu Feb 01 2024 00:00:00 (day 32 overflows into next month!)

new Date(2024, 0, 0)
// → Sun Dec 31 2023 00:00:00 (day 0 = last day of previous month!)

Getting the date components

Getting the day of the week

The code belo returns the number.

  • 0 - Sunday
  • 1 - Monday
  • 2 - Tuesday
  • 3 - Wednesday
  • 4 - Thursday
  • 5 - Friday
  • 6 - Saturday

const specificDate = new Date('2024-06-03');
console.log(specificDate);

day = specificDate.getDay()
console.log(day);

Getting the day of the month


    const specificDate = new Date('2024-02-05');
console.log(specificDate);

dayDate = specificDate.getDate();
console.log(dayDate);

Getting the year


const specificDate = new Date('2024-02-05');
console.log(specificDate);

year = specificDate.getFullYear();
console.log(year); // 2024

Getting hours and minutes


const specificDate = new Date('2024-02-05T10:30:00');
console.log(specificDate);

hours = specificDate.getHours();
console.log(hours); // 10

minutes = specificDate.getMinutes();
console.log(minutes); // 30

Getting milliseconds since 1 January 1970


const specificDate = new Date('2024-02-05T10:30:00');
console.log(specificDate);

milliseconds = specificDate.getTime();
console.log(milliseconds); // 1707085800000

You can also set the date


const specificDate = new Date('2024-02-05T10:30:00');
setDate = specificDate.setDate(15);
console.log(setDate); // 1707085800000
// The date is now set to 15th February 2024
