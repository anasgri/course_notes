Using utility classes

Utility classes can be used as a quick way to modify your website without altering the html. just by assigning certain elements to the class.

Below is the list of some usefull utility classes.

  • text-center: Centers text.
  • bg-light, bg-dark: For background colors.
  • m-3, p-3: For margin and padding.
  • d-flex, justify-content-center: For flex layouts.

Bootstrap Spacing Utility Classes

Format: {property}{sides}-{size}
Property: m = margin, p = padding
Sides: (none)=all sides, t=top, b=bottom, s=start(left), e=end(right)
Size: 0 to 5 (0 = none, 5 = largest)

Quick reference table

Class Property Side affected
m-* margin all 4 sides
mt-* margin top only
mb-* margin bottom only
ms-* margin start / left only
me-* margin end / right only
p-* padding all 4 sides
pt-* padding top only
pb-* padding bottom only
ps-* padding start / left only
pe-* padding end / right only

Bonus: mx-*/px-* set left+right together, and my-*/py-* set top+bottom together — used above to isolate single sides in each demo.

Changing how the elements are displayed.

  • d-flex: turns the element into a flex container
  • justify-content-* and align-items-* control layout

<div class="d-flex justify-content-between align-items-center">
<span>Left</span>
<span>Right</span>
</div>
