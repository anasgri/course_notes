Display: inline-flex

If the display:flex is applied to the container, the comtainer itself takes all the space in the specified flex-direction

There is an option to set the display to inline-flex, which whill allow the flex containers themselves become an inline elements

html


     <!DOCTYPE html>
<html>
<head>
  <title>Inline</title>
  <link href='style.css' rel='stylesheet' />
  <link href='https://fonts.googleapis.com/css?family=Roboto+Mono' rel='stylesheet'>
</head>

<body>
  <h1>Inline-flex</h1>
  <div class='container'> <!--- This is the first inline container -->
    <div class='box'> 
      <h3>1</h3>
    </div>
    <div class='box'>
      <h3>2</h3>
    </div>
    <div class='box'>
      <h3>3</h3>
    </div>
  </div>
  <div class='container'> <!--- This is the second inline container -->
    <div class='box'>
      <h3>1</h3>
    </div>
    <div class='box'>
      <h3>2</h3>
    </div>
    <div class='box'>
      <h3>3</h3>
    </div>
  </div>
</body>
</html>

css



    body {
  margin: 0;
  border: 0;
  font-family: 'Roboto Mono', monospace;
  text-align: center;
}

h1 {
  font-size: 18px;
  text-align: center;
}

.container {
  width: 150px;
  border: 1px solid grey;
  display: inline-flex; /* The containers are in-line because of that line */
}

.box {
  background-color: dodgerblue;
  height: 75px;
  width: 75px;
  border: 1px solid turquoise;
}
