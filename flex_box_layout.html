Flexbox layout

Flexbox is a powerful CSS layout module that makes it easier to design flexible and responsive layout structures without using floats or complicated positioning. It helps align and distribute space among items in a container

To use the Flexbox add the display:flex to the container.

All children elements within this container are automatically positioned.

The default direction is horizontal (row).

Note on the display property.

The display property is defining how the item is displayed.

The most common values arr inline, block and none

none - means hidden, the document looks like the element does not exist.

block - the element is going to take all the width of the parent container.

inline- Displays an element as an inline element (like ). Any height and width properties will have no effect. This is default.

inline-block - Displays an element as an inline-level block container. The element itself is formatted as an inline element, but you can apply height and width values.

Basic Flexbox example

There is also a gap property, that adds the gap between the items.

Flexbox has two axes:

  • Main axis: the direction in which flex items are laid out (default is left to right).
  • Cross axis: perpendicular to the main axis.

Using justify-content that aligns items to the main axis

justify-content options:

  • flex-start;
  • flex-end;
  • center;
  • space-between;
  • space-around;
  • space-evenly;

Align-items

Align-items aligns items along the cross axis.

  • stretch (default)
  • flex-start
  • flex-end
  • center
  • baseline

Flex-wrap

By default the wrapping us wrapped in the single line.

You can use flex-wrap to aloow the wrapping.

  • nowrap (default)
  • wrap
  • wrap-reverse

How the flex wrap works

  • flex-direction: row + flex-wrap: wrap → items fill left-to-right, then wrap into new rows stacked downward.
  • flex-direction: column + flex-wrap: wrap → items fill top-to-bottom, then wrap into new columns extending rightward.

The condition that has to be true either way: the container needs a bounded size on the axis items are flowing along, or there's nothing for the browser to "run out of." For row, that's a bounded width (or the items' total width exceeding the container's width). For column, that's a bounded height. For flex-direction: column + flex-wrap to work, the container should have the set finite height.

Flex-flow

The two properties flex-direction and flex-wrap are used so often together that the shorthand property flex-flow was created to combine them. This shorthand property accepts the value of the two properties separated by a space.


.pond {
display: flex;
flex-flow: column wrap;
}

align-content

The align-content property aligns the flex lines. It only has effect when flex items wrap onto multiple lines.

This property can have one of the following values:

  • stretch (default)
  • center
  • flex-start
  • flex-end
  • space-between
  • space-around
  • space-evenly

Controlling Item Size with flex


  .item {
    flex: 1;
  }

Flex is applied to the indivisual items. Not the container. It controls what proportion of the available space the item can take.

Other properties that are applied to the children elements (not the container)

flex-shrink property

The flex-shrink property specifies how the item will shrink relative to the rest of the flexible items inside the same container.


  div:nth-of-type(2) {
  flex-shrink: 3;
}

flex-grow

The flex-grow CSS property specifies how much a flex item will grow relative to the other flex items inside the same container when extra free space is available.


div:nth-of-type(1) {flex-grow: 1;}
div:nth-of-type(2) {flex-grow: 3;}
div:nth-of-type(3) {flex-grow: 1;}

order

order - Specifies the display order of the flex items inside the flex container. Default is 0; higher numbers appear later


<div class="flex-container">
<div style="order: 3">1</div>
<div style="order: 2">2</div>
<div style="order: 4">3</div>
<div style="order: 1">4</div>
</div>

align-self property

The align-self property specifies the alignment in the block direction for the selected item inside a flexbox or grid container.

For pages in English, block direction is downward and inline direction is left to right.

💡 To align a grid item in the inline direction instead of the block direction, use justify-self or justify-items properties.

align-self overrides align-items for individual items.
