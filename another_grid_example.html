You can also have the shorthand version of the possitioning, whithiut having the grid-column-start: 3; grid-column-end: 4; 


      .item {
        grid-column: 1/3; /* equivalent to grid-column-start: 1; grid-column-end: 3; */
        grid-row: 1/2; /* equivalent to grid-row-start: 1; grid-row-end: 2; */

      }

Grid template areas

grid-template areas are used to create the named layout sections 


      .grid-container {
        grid-template-areas: "header header" "sidebar main" "footer footer";
        grid-template-columns: 1fr 3fr;
      }

Later you can assign areas to items.


      .header { grid-area: header;}
      .sidebar {grid-area: sidebar;}
      .main {grid-area: main;}
      .footer {grid-area: footer;}
  • Explicit Grid: You define rows and columns
  • Implicit Grid: Created automatically when items exceed defined structure You can control implicit rows/columns with grid-auto-rows and grid-auto-columns

Common grid properties

  • grid-template-rows: Defines row layout.
  • grid-auto-rows: Specifies default row size.
  • justify-items and align-items: Aligns items inside cells.

For the items

  • grid-template-rows: Defines row layout.
  • grid-auto-rows: Specifies default row size.
  • justify-items and align-items: Aligns items inside cells.

You can use the following properties for alignment:

  • justify-items and align-items for individual cell content
  • justify-content and align-content for the whole grid
  • gap, row-gap, and column-gap for spacing
