Tables

The basic syntaxis for the table is shown below


<table> 
<tr>
    <th>Header contents 1</th><th>Header contents 2</th>
</tr>
<tr>
    <td>cell contents 1</td><td>cell contents 2</td>
</tr>
</table>

The table starts with the <table> tag and closes with the </table> tag.

The <tr> and </tr> tags are used to make the table row.

The <th> and </th> tags are used to make the heading cells.

The <td> and </td> tags are used to make the normal cells.

<thead>, <tbody> and <tfoot> tags

These tags do not change the representation of the table by themselves, but divide the table in the meaningfull parts 


<table>
<thead>
<tr>
    <th>Month</th>
    <th>Savings</th>
</tr>
</thead>
<tbody>
<tr>
    <td>January</td>
    <td>$100</td>
</tr>
<tr>
    <td>February</td>
    <td>$80</td>
</tr>
</tbody>
<tfoot>
<tr>
    <td>Sum</td>
    <td>$180</td>
</tr>
</tfoot>
</table>
Month Savings
January $100
February $80
Sum $180

scope attribute

Scope attribute is also used to group some rows and tables together. It does not change the appearance but adds meaning to the table. It spefifies what is the meaning for the header cells.

There are three possible values that scope attribute can take

  • col - Specifies that the cell is a header for a column
  • row - Specifies that the cell is a header for a row
  • colgroup - Specifies that the cell is a header for a group of columns
  • rowgroup - Specifies that the cell is a header for a group of rows 

<table border="1">
  <caption>Contact Information</caption>
  <tr>
    <td></td>
    <th scope="col">Name</th>
    <th scope="col">Phone#</th>
    <th scope="col">Fax#</th>
    <th scope="col">City</th>
  </tr><tr>
    <td>1.</td>
    <th scope="row">Joel Garner</th>
    <td>412-212-5421</td>
    <td>412-212-5400</td>
    <td>Pittsburgh</td>
  </tr><tr>
    <td>2.</td>
    <th scope="row">Clive Lloyd</th>
    <td>410-306-1420</td>
    <td>410-306-5400</td>
    <td>Baltimore</td>
  </tr><tr>
    <td>3.</td>
    <th scope="row">Gordon Greenidge</th>
    <td>281-564-6720</td>
    <td>281-511-6600</td>
    <td>Houston</td>
  </tr>
</table>

HTML table colspan and rowspan attributes

The colspan and rowspan attributes defines how many cells the cell takes. This is similar to having the merged cells 


<table border="1">
  <tr>
    <th colspan="2">Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Jill</td>
    <td>Smith</td>
    <td>43</td>
  </tr>
  <tr>
    <td>Eve</td>
    <td>Jackson</td>
    <td>57</td>
  </tr>
</table>
Name Age
Jill Smith 43
Eve Jackson 57

Table Styling with CSS

Layout and Spacing

Setting equal column width

Fixed Layout – Use table-layout: fixed and width: 50% to set even column widths, that going to take up 50% of the availabel space. 


  <style>
  table {
  table-layout: fixed;
  width: 50%;
}
</style>

<table border="1">
  <tr>
    <th>Company</th>
    <th>Contact</th>
    <th>Country</th>
  </tr>

    <td>Maria Anders</td>

  </tr>

Using border collapse or separate

Border Collapsing – Use border-collapse: collapse to merge borders. Use border-spacing with border-collapse: separate to add gaps. 


<style>
  table {
  table-layout: fixed;
  width: 50%;
  border-collapse: collapse;
}
</style>

<table border="1">
  <tr>
    <th>Company</th>
    <th>Contact</th>

Padding and border styling

Cell Padding – Add padding to <td> and <th> to improve readability.


<style>
table {
  table-layout: fixed;
  width: 100%;
  border-collapse: collapse;
}
th, td {
  padding: 10px;
  border: 1px solid #ccc;
}

</style>
