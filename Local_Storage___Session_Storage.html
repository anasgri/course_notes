Local Storage & Session Storage

Local and Session Storage

Maintains State: Keeps data available between page reloads.

Improves User Experience: Saves preferences and settings.

Reduces Server Load: Minimizes unnecessary API calls.

Local Storage and Session Storage are like a locker. Local Storage is a permanent locker, while Session Storage is a temporary one that gets cleared when you leave

What is Local Storage?

  • Local Storage stores data persistently with no expiration.
    • Data is available even after the browser is closed and reopened. Stores key-value pairs

Using Local Storage

The localStorage object allows you to save key/value pairs in the browser.


    // Store data
localStorage.setItem("username", "JohnDoe");

// Retrieve data
let username = localStorage.getItem("username");
console.log(username); // "JohnDoe"

// Remove data
localStorage.removeItem("username");

// Clear all data
localStorage.clear();
  • setItem() adds data to Local Storage.
  • getItem()retrieves stored data
  • removeItem() deletes a specific item.
  • clear() removes all data

Examle below is the javaScript code that correspons to the form. 


<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>

    <form id="form">
      <label for="name">Name:</label>
      <input type="text" id="name" name="Name" required />

      const form = document.getElementById("form");
      const nameInput = document.querySelector("#name");

      form.addEventListener("submit", (event) => {
        event.preventDefault();

        const name = nameInput.value;

        if (name) {
          localStorage.setItem("name", name);
          alert("Name saved to local storage!");
          nameInput.value = "";
        } else {
          alert("Please enter a name.");
        }
      });
    
    </script>
  </body>
</html>

What is Session Storage?

  • Session Storage stores data temporarily.
  • Data is cleared when the page is closed.
  • Stores key-value pairs like Local Storage

Session Storage works similarly to Local Storage.

  • setItem() adds data to Session Storage.
  • getItem()retrieves stored data
  • removeItem() deletes a specific item.
  • clear() removes all data

  // Store data
sessionStorage.setItem("sessionID", "12345");

// Retrieve data
let sessionID = sessionStorage.getItem("sessionID");
console.log(sessionID); // "12345"

// Remove data
sessionStorage.removeItem("sessionID");

// Clear all data
sessionStorage.clear();
Feature Local Storage Session Storage
Persistence Data remains after browser is closed Data is cleared after closing the browser
Expiry No expiry Clears on session end
Storage Limit 5MB per domain 5MB per domain
Use Cases Save user preferences, theme, etc. Store temporary data like form inputs

Local and Session Storage can only store strings.

Use JSON.stringify() and JSON.parse() to store and retrieve objects.


let user = { name: "Alice", age: 30 };

// Store object
localStorage.setItem("user", JSON.stringify(user));

// Retrieve object
let retrievedUser = JSON.parse(localStorage.getItem("user"));
console.log(retrievedUser.name); // "Alice"

JSON.stringify() converts objects to strings

JSON.parse() converts strings back to objects.
