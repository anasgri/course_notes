Timers

Sometimes you want to execute code after a certain amount of time has passed.

In the case below the alert will be shown after 5 seconds (5000 ms):


function myGreeting() {
  alert("Hello!");
}
const myTimeout = setTimeout(myGreeting, 5000);

Use clearTimeout(myTimeout) to prevent myGreeting from running:


const myTimeout = setTimeout(myGreeting, 5000);

function myStopFunction() {
  clearTimeout(myTimeout);
}

setInterval()

Set interval executes the function repeatedly at specified intervals:

Below is the flashcard project where the source of the image get changed to dipaly different apples. 


<!doctype html>
<html lang="en">
<head>
<meta charset="UTF-8" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<title>Changing images</title>
</head>
<body>
<h1>Changing Images</h1>
<img id="myImage" src="red_apple_image.jpeg" alt="Image 1" width="300" />

Javascript code for changing images:


imageArray = [
        "red_apple_image.jpeg",
        "green_apple_image.jpeg",
        "yellow_apple_image.jpg",
      ];
      currentIndex = 0;
      function changeImage() {
        document.getElementById("myImage").src = imageArray[currentIndex];
        currentIndex++;
        if (currentIndex >= imageArray.length) {
          currentIndex = 0;
        }
      }
      setInterval(changeImage, 10000);
