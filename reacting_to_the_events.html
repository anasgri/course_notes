Responding to the events

This section is about the cases when the user clicks the button and something happens

Easiest option

Easiest option, directly putting the JavaScript code in the HTML


        <button onclick="alert('Hello!')">Click me</button>

Using the onclick and function


const button = document.getElementById('myButton'); // there is a button with the id 'myButton' in the HTML
// Assign a function to onclick
button.onclick = function() {
  alert('Button was clicked!');
};

More practical example with the list


const items = document.querySelectorAll('.list-item');

items.forEach(item => {
  item.onclick = function() {
    this.style.backgroundColor = 'yellow'; // only highlights the clicked item
    console.log('Clicked:', this.textContent);
  };
});
