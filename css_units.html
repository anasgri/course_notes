The units used in CSS

There are different types of the units used in the CSS

  • px: Absolute pixels, fixed size regardless of screen.
  • em: Relative to the font-size of the parent element. If em is used for margin, not for font it is relative to the font size of the element itself.
  • rem: Relative to the root (html) font size, consistent across all elements
  • %: Relative to the size of the parent container. % for font-size behaves identically to em — both resolve against the parent's computed font-size and compound when nested.

It is preferred to use the rem
