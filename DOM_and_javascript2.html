You can select the element by getElementById() and then modify its attruibutes and change styles.

  • innerText changes the visible text.
  • style modifies CSS properties.
  • setAttribute() updates attributes dynamically

let title = document.getElementById("title");

// Change content
title.innerText = "New Title";

// Change styles
title.style.color = "blue";
title.style.fontSize = "24px";

// Change attributes
title.setAttribute("class", "highlight");

querySelector

querySelectoruses CSS selectors to target elements (#id, .class, tag).

Returns the first matching element


// Select first element with class 'item'
let item = document.querySelector(".item");
console.log(item.innerText);

Like getElementById(), querySelector() can modify content and styles


let subtitle = document.querySelector(".subtitle");

// Change content
subtitle.innerText = "Updated Subtitle";

// Add a new CSS class
subtitle.classList.add("bold");

// Remove a CSS class
subtitle.classList.remove("italic");

querySelectorAll()

querySelectorAll() returns a NodeList of all matching elements. And then you can loop through them. 


  // Select all elements with class 'item'
let items = document.querySelectorAll(".item");

// Loop through and modify each item
items.forEach(function(item) {
  item.style.color = "green";
});

getElementsByClassName() and getElementsByTagName()

These methods return collections of elements by class or tag name


  // Select all elements with class 'item'
let items = document.getElementsByClassName("item");

// Select all <p> elements
let paragraphs = document.getElementsByTagName("p");
