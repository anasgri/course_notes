Types of the css selectors

Element selectors

Element selectors act on the specified elements. In the example below, all paragraphs will be red. Element selectors are also sometimes called type selectors. 


    /* Element selectors */
p {
    color: red;
}

Class selectors

Class selectors act on the elements assigned to the specific class

In the example below all elements assigned to the class .intro will be red 


/* Class selectors */
.intro {
    color: red;
}

To make the class element specific to cretain tag do as shown in the example below. The code below will result in all paragraphs assigned to class intro being colored red, but other elements that are not paragraphs will not be colored. 


/* Class selectors */
p.intro {
    color: red;
}

You can assign element to multiple classes

css


/* Multiple classes */
.intro {
    color: red;
}
.highlight {
    background-color: yellow;
}

html


<p class="intro highlight">This paragraph will be red with a yellow background.</p>
<p class="intro">This paragraph will be red.</p>
<p class="highlight">This paragraph will have a yellow background.</p>

This paragraph will be red with a yellow background.

This paragraph will be red.

This paragraph will have a yellow background.

Targeting elements with multiple classes and ignoring the ones asigned to one class

You can also make the class selectors that will exclusively target elements that are assigned to several classes and ignore the elements that are assigned to only one of the classes. This is done by combining the class selectors together.

In the example below the selector li.spacious.elegant targets the elements that is assigned to multiple classes. 


<!DOCTYPE HTML>
<html>
<head><title>example css</title>
<style>
li.spacious.elegant {
  margin: 2em;
  padding: 1em;
  border: 1px solid #ccc;
}
</style>
</head>
<body>
<ul>
  <li class="spacious elegant">Item one</li>
  <li class="spacious elegant retro">Item two</li>
  <li class="elegant">Item three (won't match)</li>
  <li class="spacious">Item four (won't match)</li>
</ul>
</body>
</html>
  • Item one
  • Item two
  • Item three (won't match)
  • Item four (won't match)

ID selectors

The ID selectors target the elements with the specific ID


/* ID selectors */
#main-info {
    color: red;
}

Important note

The class name must be one word

The characters that are allowed in the class names:

  • Letters: a-z, A-Z
  • Digits: 0-9
  • Hyphens: -
  • Underscores: _
  • Any character outside the ASCII range (Unicode code points ≥ U+0080) — so accented letters, emoji, CJK characters, etc. are technically valid Escaped characters using backslash notation (e.g., \@ to include an otherwise-illegal character)

Restrictions on structure:

  • Cannot start with a digit (.1class is invalid)
  • Cannot start with two hyphens, or a hyphen followed by a digit (.-1class is invalid) — because that pattern is reserved for vendor-prefixed identifiers
  • A single hyphen alone is not a valid identifier

Attribute selectors

Attribute selectors target the elements that have the specific attribute or attribute value.

The simplest attribute selector is shown below:

It is going to target all links and other elements that have an href attribute: 


  [href]{
   color: magenta;
}

In the example below the link that has the title attribute gets selected and recolored into purple. 


<!DOCTYPE HTML>
<html>
<head><title>example css</title>
<style>
a[title] {
  color: purple;
}
</style>
</head>
<body>
<ul>
<li>
<a href="https://example.com" title="Visit Example">Link that contains example</a> </li>
<li>
<a href="https://sample.com">Link without title (default color)</a> </li>
</ul>
</body>
</html>

  • Link with title (purple)
  • Link without title (default color)

[attr] - Represents elements with an attribute name of attr. 


<!DOCTYPE HTML>
<html>
<head><title>example css</title>
<style>
/* <a> elements with an href matching "https://example.org" */
a[href="https://example.org"] {
  color: green;
}
</style>
</head>
<body>
<ul>
<li>
<a href="https://example.org" title="Visit Example">Link matching the selector (green)</a> </li>
<li>
<a href="https://example.com">Link that is not targeted by selector (default color)</a> </li>
</ul>
</body>
</html>
  • Link matching the selector (green)
  • Link that is not targeted by selector (default color)

[attr=value]- Represents elements with an attribute name of attr whose value is exactly value.

In the example above the href link was identical to the value targeted by selector.

[attr$=value] - Represents elements with an attribute name of attr whose value is suffixed (followed) by value.

In other words, this selector targets the attributes that end with the specified substring

i or I means case insensitive

Targeting the attribute that starts with the specific substring

Targeting the attribute based on substring or substring followed by hyphen

[attr|=value] Represents elements with an attribute name of attr whose value can be exactly value or can begin with value immediately followed by a hyphen, - (U+002D). It is often used for language subcode matches.

Descendant Combinator

In addition to chaining selectors to select elements, CSS also supports selecting elements that are nested within other HTML elements, also known as descendants. For instance, consider the following HTML:

html


<ul class='main-list'>
  <li> ... </li>
  <li> ... </li>
  <li> ... </li>
</ul>

css


/* Selects all <li> elements that are descendants of an element with the class 'main-list' */
.main-list li {
  color: blue;
}

In the example above, .main-list selects the element with the.main-list class (the <ul> element).

The descendant <li>‘s are selected by adding li to the selector, separated by a space. This results in .main-list li as the final selector.

Selecting elements in this way can make our selectors even more specific by making sure they appear in the context we expect.
