JavaScript string methods

String methods let you extract, modify, search and format text. Strings are immutable, so every method below returns a new value and leaves the original string unchanged. Indexes start at 0.

Extracting parts of a string

slice(start, end) returns the part of the string from start up to (not including) end. If end is left out it goes to the end of the string. Negative numbers count from the end. 


let a = 'Geeks for Geeks';

console.log(a.slice(0, 5)); // "Geeks"
console.log(a.slice(6, 9)); // "for"
console.log(a.slice(10));   // "Geeks"
console.log(a.slice(-5));   // "Geeks"

substring(start, end) works like slice() but treats negative numbers as 0. 


let str = "Mind, Power, Soul";

console.log(str.substring(6, 11)); // "Power"

substr(start, length) returns a number of characters starting at start. It is deprecated, so prefer slice(). 


let str = "Mind, Power, Soul";

console.log(str.substr(6, 5)); // "Power"

charAt(index) returns the character at the given index. 


let gfg = 'GeeksforGeeks';

console.log(gfg.charAt(0)); // "G"
console.log(gfg.charAt(5)); // "f"

at(index) also returns the character at an index, but it accepts negative numbers to count back from the end. 


let word = 'Hello';

console.log(word.at(0));  // "H"
console.log(word.at(-1)); // "o"
console.log(word.at(-2)); // "l"

charCodeAt(index) returns the Unicode (UTF-16) number of the character at the given index. 


console.log('GeeksforGeeks'.charCodeAt(0)); // 71

codePointAt(index) returns the code point value at an index. Unlike charCodeAt() it handles characters such as emoji correctly. 


console.log('A'.codePointAt(0));  // 65
console.log('😀'.codePointAt(0)); // 128512

Searching a string

includes(text) returns true if the string contains the given text. It is case-sensitive. 


let s = 'Hello, world';

console.log(s.includes('world')); // true
console.log(s.includes('World')); // false

startsWith(text, position) checks whether the string starts with the given text. The optional second argument is where to start checking. 


let s = 'Hello, world';

console.log(s.startsWith('Hello'));   // true
console.log(s.startsWith('world'));   // false
console.log(s.startsWith('world', 7)); // true

endsWith(text, length) checks whether the string ends with the given text. The optional second argument is how many characters of the string to look at. 


let s = 'Hello, world';

console.log(s.endsWith('world'));  // true
console.log(s.endsWith('Hello'));  // false
console.log(s.endsWith('Hello', 5)); // true

indexOf(text, from) returns the index of the first match, or -1 if there is none. 


let s = 'Hello, world';

console.log(s.indexOf('o'));    // 4
console.log(s.indexOf('o', 5)); // 8
console.log(s.indexOf('z'));    // -1

lastIndexOf(text) returns the index of the last match, or -1 if there is none. 


let s = 'Hello, world';

console.log(s.lastIndexOf('o')); // 8
console.log(s.lastIndexOf('l')); // 10
console.log(s.lastIndexOf('z')); // -1

Regular expressions

match(regex) searches the string using a regular expression. Without the g flag it returns the first match (with extra details), with g it returns an array of all matches, and it returns null if nothing matches. 


let text = 'a1b22c333';

console.log(text.match(/\d+/)[0]); // "1"
console.log(text.match(/\d+/g));   // ["1", "22", "333"]
console.log(text.match(/x/));      // null

matchAll(regex) returns an iterator of all matches, including their positions. The regular expression must use the g flag. 


let text = 'a1b22c333';

for (const m of text.matchAll(/\d+/g)) {
  console.log(m[0], m.index);
}
// "1" 1
// "22" 3
// "333" 6

search(regex) returns the index of the first regular expression match, or -1 if there is none. 


console.log('Hello 2026'.search(/\d/)); // 6
console.log('Hello'.search(/\d/));      // -1

Replacing text

replace(search, newText) replaces the first match, which can be a string or a regular expression. 


let str = "Mind, Power, Soul";

console.log(str.replace("Power", "Space")); // "Mind, Space, Soul"

replaceAll(search, newText) replaces every match. 


let str = "Mind, Power, Power, Soul";

console.log(str.replaceAll("Power", "Space")); // "Mind, Space, Space, Soul"

Changing case

toUpperCase() and toLowerCase() change every character to upper or lower case. 


let word = 'Hello World';

console.log(word.toUpperCase()); // "HELLO WORLD"
console.log(word.toLowerCase()); // "hello world"

toLocaleUpperCase(locale) and toLocaleLowerCase(locale) change case using the rules of a language. The Turkish letter i is a common example. 


console.log('i'.toLocaleUpperCase('en-US')); // "I"
console.log('i'.toLocaleUpperCase('tr'));    // "İ"
console.log('I'.toLocaleLowerCase('tr'));    // "ı"

Joining, repeating and splitting

concat(str1, str2, ...) joins strings together and returns the combined string. 


let hello = 'Hello';

console.log(hello.concat(', ', 'world')); // "Hello, world"

repeat(count) returns a new string with the original repeated the given number of times. 


console.log('ab'.repeat(3));  // "ababab"
console.log('-'.repeat(10));  // "----------"
console.log('x'.repeat(0));   // ""

split(separator) breaks a string into an array of substrings at every separator. 


let geeks = 'stands-for-GeeksforGeeks';

console.log(geeks.split('-')); // ["stands", "for", "GeeksforGeeks"]

Removing whitespace

trim() removes whitespace from both ends, trimStart() from the beginning only and trimEnd() from the end only. None of them take an argument. 


let gfg = '   GFG   ';

console.log(gfg.length);         // 9
console.log(gfg.trim().length);  // 3
console.log(gfg.trimStart());    // "GFG   "
console.log(gfg.trimEnd());      // "   GFG"

Padding

padStart(length, pad) adds the pad text to the left until the string reaches the given length. padEnd(length, pad) does the same on the right. 


let stone = "Soul";

console.log(stone.padStart(9, "Mind ")); // "Mind Soul"
console.log(stone.padEnd(10, " Power"));  // "Soul Power"
console.log('7'.padStart(3, '0'));       // "007"

Comparing and normalizing

localeCompare(other) compares two strings and returns a negative number, 0 or a positive number. It is handy for sorting text. 


console.log('a'.localeCompare('b')); // negative number
console.log('b'.localeCompare('a')); // positive number
console.log('a'.localeCompare('a')); // 0

let fruit = ['Zebra', 'apple', 'Mango'];
console.log(fruit.sort((x, y) => x.localeCompare(y))); // ["apple", "Mango", "Zebra"]

normalize() returns a Unicode normalization form of the string. It makes two different ways of writing the same character equal. 


let combined = 'e\u0301'; // "e" followed by a combining accent
let single = '\u00e9';    // "é" as one character

console.log(combined.length);              // 2
console.log(combined === single);          // false
console.log(combined.normalize() === single); // true

Converting to a string value

toString() and valueOf() return the string value itself. They matter mostly when you have a String object instead of a plain string. 


let plain = 'Hi';
let obj = new String('Hi');

console.log(plain.toString()); // "Hi"
console.log(plain.valueOf());  // "Hi"
console.log(typeof obj);            // "object"
console.log(typeof obj.valueOf());  // "string"

Well-formed strings

isWellFormed() checks that the string has no lone surrogates (half of a two-part Unicode character). 


console.log('abc'.isWellFormed());      // true
console.log('ab\uD800'.isWellFormed()); // false

toWellFormed() replaces lone surrogates with the Unicode replacement character (\uFFFD). 


let broken = 'ab\uD800';
let fixed = broken.toWellFormed();

console.log(fixed);               // "ab\uFFFD"
console.log(fixed.charCodeAt(2)); // 65533
console.log(fixed.isWellFormed()); // true

Static methods on String

String.fromCharCode(code1, code2, ...) builds a string from UTF-16 code units. Call it on String, not on a string value. 


console.log(String.fromCharCode(72, 105));     // "Hi"
console.log(String.fromCharCode(65, 66, 67));  // "ABC"

String.fromCodePoint(code1, code2, ...) builds a string from code point values, including ones above 65535 such as emoji. 


console.log(String.fromCodePoint(72, 105)); // "Hi"
console.log(String.fromCodePoint(128512));  // "😀"

String.raw is a template tag that returns the raw text of a template literal without processing escape characters such as \n. 


console.log(`Line 1\nLine 2`);
// Line 1
// Line 2

console.log(String.raw`Line 1\nLine 2`);
// Line 1\nLine 2

console.log(String.raw`C:\new\table`);
// C:\new\table

Method that returns HTML

anchor(name) creates an HTML anchor element from the string. It is a legacy method, so in modern code build elements with the DOM instead. 


console.log('Home'.anchor('top'));
// <a name="top">Home</a>
