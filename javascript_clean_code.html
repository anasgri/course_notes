JavaScript clean code

  • Choose meaningfull names for variables
  • Use camelcase for varables and functions myVariable
  • Use Pascalcase PascalCase for classes and condtructors
  • use meaningfull self explanatory names.
  • Functions should perform the single task and be easy to understand
  • Do not use + for string concatenation
    • 
// Poor practice
let name = "Alice";
let greeting = "Hello, " + name + "!";

// Better practice
let name = "Alice";
let greeting = `Hello, ${name}!`;
