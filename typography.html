Typography

The very basic way of defining the font family is shown below:


.p1 {
  font-family: "Times New Roman", Times, serif;
}

.p2 {
  font-family: Arial, Helvetica, sans-serif;
}

.p3 {
  font-family: "Lucida Console", "Courier New", monospace;
}

Note on why some values are in brackets

A specific font name ("Lucida Console", "Courier New") — these get quoted only because they contain spaces. Quoting isn't required for font names generally; it's required when the name has spaces, numbers at the start, or special characters that would otherwise confuse the CSS parser. A single-word font like Arial doesn't need quotes: font-family: Arial, sans-serif; is valid.

A generic family keyword (serif, sans-serif, monospace, cursive, fantasy, system-ui) — these are reserved CSS keywords, not actual font names. Quoting a keyword would turn it into a literal string the browser tries to match against an installed font named "monospace", which doesn't exist as such. So generic keywords are never quoted.

Importing the web font using font-face

Fonts can also be added using a @font-face ruleset in your CSS stylesheet instead of using a <link> element in your HTML document. As mentioned earlier, fonts can be downloaded just like any other file on the web. They come in a few different file formats, such as:

  • OTF (OpenType Font)
  • TTF (TrueType Font)
  • WOFF (Web Open Font Format)
  • WOFF2 (Web Open Font Format 2)

      @font-face {
  font-family: 'MyParagraphFont';
  src: url('fonts/Roboto.woff2') format('woff2'),
       url('fonts/Roboto.woff') format('woff'),
       url('fonts/Roboto.ttf') format('truetype');
}
  • The @font-face at-rule is used as the selector. It's recommended to define the @font-face ruleset at the top of your CSS stylesheet.
  • Inside the declaration block, the font-family property is used to set a custom name for the downloaded font. The name can be anything you choose, but it must be surrounded by quotation marks. In the example, the font is named 'MyParagraphFont', as this font will be used for all paragraphs.
  • The src property contains three values, each specifying the relative path to the font file and its format. In this example, the font files are stored inside a folder named fonts within the working directory.

The different formats are a progression of standards for how fonts will work with different browsers, with WOFF2 being the most progressive. It's a good idea to include TTF, WOFF, and WOFF2 formats with your @font-face rule to ensure compatibility on all browsers.

Common text properties

  • color: Changes text color.
  • font-size: Adjusts text size.
  • font-family: Sets font type.
  • text-align: Aligns text (left, right, center).
  • text-decoration: Adds effects (underline, line-through).
  • font-weight: Adjusts text boldness
  • line-height: defines the distance between the lines
  • text-transform - controls how an element's text capitalization is styled and displayed on a webpage without changing the original HTML source.

font-weight

The font-weight property can take any one of these keyword values:

  • bold: Bold font weight.
  • normal: Normal font weight. This is the default value.
  • lighter: One font weight lighter than the element's parent value.
  • bolder: One font weight bolder than the element's parent value

Numerical Values for font-weight

Numerical values can range from 1 (lightest) to 1000 (boldest), but it is common practice to use increments of 100.

A font weight of 400 is equal to the keyword value normal, and a font weight of 700 is equal to bold.

font-style

Font style makes the text italic

possible values

  • font-style: normal;
  • font-style: italic;
  • font-style: oblique;
  • font-style: oblique 10deg;

In the oblique 10deg; the 10deg; specifies the incline of the text.

text-align

for text-align the permitted propreties are:

  • left: Content aligns along the left side.
  • right: Content aligns along the right side.
  • center: Content is centered between the left and right edges.
  • justify: Content spaces out to fill the full width of the container.
  • start: Aligns to the start edge based on text direction (left for LTR, right for RTL).
  • end: Aligns to the end edge based on text direction.
  • match-parent: Inherits the alignment from the parent element's direction.

line-height property.

text-transform property

Common values for the text transform:

  • uppercase: Converts every letter in the element to capital letters
  • lowercase: Converts every letter in the element to small letters.
  • capitalize: Changes the very first letter of every word into a capital letter. 
    • 
      .uppercase_text {
        text-transform: uppercase;
    }

    Letter Spacing

    The letter-spacing property is used to set the horizontal spacing between the individual characters in an element. It's not common to set the spacing between letters, but it can sometimes help the readability of certain fonts or styles. The letter-spacing property takes length values in units, such as 2px or 0.5em. 

    
  p {
  letter-spacing: 2px;
}

    Word Spacing

    You can set the space between words with the word-spacing property. It's also not common to increase the spacing between words, but it may help enhance the readability of bolded or enlarged text. The word-spacing property also takes length values in units, such as 3px or 0.2em. 

    
      h1 {
  word-spacing: 0.3em;
}

    For word spacing, using em values are recommended because the spacing can be set based on the size of the font.
