JavaScript arrays

The arrays are defined in the same way as in python, there is just ; at the end. 


let fruits = ["apple", "banana", "cherry"];

Declaring the arrays


      let multyValues = [];
      let multyValues1 = new Array();
      let multyValues2 = Array();
      let multyValues3 = Array(3); // [ <3 empty items > ]

You can access the specific element by index;


console.log(fruits[0]);
console.log(fruits[1]);

You can do the same using at


const fruits = ["Banana", "Orange", "Apple", "Mango"];
let fruit = fruits.at(2);

Array methods, javascript

The length property returns the length (size) of an array


const fruits = ["Banana", "Orange", "Apple", "Mango"];
let size = fruits.length;

The length property can be also used to set the size of the array, in this case, the array is cut from the beginning to match the specified number. 


const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.length = 2; // ["Banana", "Orange"];

he pop() method removes the last element from an array:


const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.pop();

The pop() method returns the value that was "popped out":


const fruits = ["Banana", "Orange", "Apple", "Mango"];
let fruit = fruits.pop();

Adding the elements to the array

The push() method adds a new element to an array (at the end):


const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.push("Kiwi");

The push() method returns the new array length:


const fruits = ["Banana", "Orange", "Apple", "Mango"];
let length = fruits.push("Kiwi");

Inserting the element inside the array by index


const fruits = ['Apple', 'Banana', 'Date'];

// Insert 'Cherry' at index 2
fruits.splice(2, 0, 'Cherry');

array.splice(index, 0, element). Passing 0 as the second argument ensures that no elements are deleted, turning the operation into a pure insertion.

Removing elements from the lists

The shift() method removes the first array element and "shifts" all other elements to a lower index. 


  const fruits = ["Banana", "Orange", "Apple", "Mango"];
  fruits.shift();

You can declare arrays with const, despite being modified, the array is saved in the same place.

Different ways how to loop through the array

Using the conventional loop


let animals = ["dog", "cat", "rabbit"];

// Using for loop
for (let i = 0; i < animals.length; i++) {
  console.log(animals[i]);
}

Using the arrow function


let animals = ["dog", "cat", "rabbit"];
// Using forEach
animals.forEach(animal => console.log(animal));

Using for of


let animals = ["dog", "cat", "rabbit"];
for (let animal of animals) {
  console.log(animal);
}
