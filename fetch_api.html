Fetch API

The Fetch API is a modern JavaScript interface that allows you to make HTTP requests to servers and handle responses easily. It simplifies working with APIs by using Promises and provides a cleaner alternative to XMLHttpRequest.

Using the Fetch API is like ordering food through an app. You request the order (GET), send special instructions (POST), and get a response when your food is ready.

Basic synatxis of the Fetch API


fetch(url, options)
  .then((response) => {
    // Handle response
  })
  .catch((error) => {
    // Handle errors
  });
  • url: The endpoint where the request is sent. on the same website you might have different urls for different actions, based on what do you want to do.
  • options specify, if you are doing get, post request and if you need any aditiona information like API key.
  • Returns a Promise that resolves to a Response object.

The example how fetch can be used to retrieve data from the server


fetch('https://api.example.com/data')
  .then((response) => {
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }
    return response.json(); // here the function ends
  })
  .then((data) => console.log(data))
  .catch((error) => console.error('Error:', error));

The synataxis is the following fetch('url').then((response) => {...})

where the response is the variable that stoires the Response Object.

Within the function we check if the response is ok or not. That is if the promis is fulfilled or not.

The key rule: whatever a .then() callback returns becomes the value the next .then() receives.

Thus data in this example stores response.json()

.catch((error) => console.error('Error:', error)); returns whatever errors that happens in the process.

The example how the fetch can be used to send POST request


      fetch('https://api.example.com/addUser', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'Alice',
    email: 'alice@example.com',
  }),
})
  .then((response) => {
    if (!response.ok) {
      throw new Error(`Error! Status: ${response.status}`)
    }
    return response.json()
  })
  .then((data) => console.log('User added:', data))
  .catch((error) => console.error('Error:', error))

To make a post request, you need the information to send.

https://api.example.com/addUser - is where the information gets sent

headers specify the type if the informstion

body contains the JSON data that will be sent to the server.

Using Async/Await with Fetch API


      async function fetchData() {
  try {
    let response = await fetch('https://api.example.com/data')
    if (!response.ok) {
      throw new Error(`Error! Status: ${response.status}`)
    }
    let data = await response.json()
    console.log(data)
  } catch (error) {
    console.error('Error:', error)
  }
}

fetchData()

Step by syep going through this function

  • async function fetchData() - ensures that the function is asynchronous, it does not wait for other JavaScript code 
  •

    This checks the response. await means we might have to wait for response. Mandatory with async.

  • throw new Error - this code lets user to create a custom error.
  • let data = await response.json() console.log(data) - saves the response.json in data variable.
  • catch section cates the errors

Sending POST request using FormData


let formData = new FormData()
formData.append('username', 'JohnDoe')
formData.append('age', 30)

fetch('https://api.example.com/upload', {
  method: 'POST',
  body: formData,
})
  .then((response) => response.json())
  .then((data) => console.log('Data uploaded:', data))
  .catch((error) => console.error('Error:', error))
