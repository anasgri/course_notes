Handling API errors

Common API errors

  • Network Errors: Internet connection issues.
  • Server Errors (5xx): Something went wrong on the server.
  • Client Errors (4xx): Usually due to bad requests from your app.
  • Invalid JSON or Data Format: Server sends unexpected or broken da

Steps to follow

Check the HTTP status code with .ok before parsing the response.


fetch('https://api.example.com/data')
  .then((response) => {
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`)
    }
    return response.json()
  })
  .then((data) => console.log(data))
  .catch((error) => console.error('Error:', error))

response.ok returns true if status code is between 200–299.

Helps catch bad status responses early.

Catching Network Errors with catch()

Network errors are caught using the .catch() method


fetch('https://api.example.com/data')
  .then((response) => response.json())
  .then((data) => console.log(data))
  .catch((error) => console.error('Network error:', error))

Handles situations like no internet connection or invalid domains.

Try...Catch with Async/Await

Using try...catch with async/await provides cleaner error handling


    async function fetchData() {
  try {
    let response = await fetch('https://api.example.com/data')
    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`)
    }
    let data = await response.json()
    console.log(data)
  } catch (error) {
    console.error('Fetch failed:', error)
  }
}

Add retry logic using the for loop

In this example we have three attempts.


    async function fetchWithRetry(url, attempts = 3) {
  for (let i = 0; i < attempts; i++) {
    try {
      const response = await fetch(url)
      if (!response.ok) throw new Error()
      return await response.json()
    } catch (e) {
      if (i === attempts - 1) throw e
    }
  }
}

Give users helpful feedback instead of technical errors using showError 


function showError(message) {
  let errorBox = document.getElementById('errorBox')
  errorBox.innerText = message
  errorBox.style.display = 'block'
}

showError('Unable to load data. Please try again later.')
