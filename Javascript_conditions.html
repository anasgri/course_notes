JavaScript conditionals

Conditionals allow your code to respond to different situations. You can run different blocks of code depending on whether a condition is true or false 


if (age >= 18) { 
    console.log("You can enter"); } else 
{ 
    console.log("You can not enter"); 
}

General synatxis


if (condition) {
    do something;
} else 
{
    do something else;
}

Basic example


  let raining = true;
  if (raining) {
    console.log("Its raining");
  }
  else {
    console.log("Its not raining");
  }

Example with multiple conditions


let raining = true;
let haveUnmbrella = true;
  if (raining && haveUnmbrella) {
    console.log("Its raining. but you can come out");
  }
  else {
    console.log("Its not raining");
  }

You can use else if if to test multiple conditions


let grade = 85;
if (grade >= 90) {
  console.log("Excellent");
}
else if (grade >= 80) {
  console.log("very good");
}
else if (grade >= 70) {
  console.log("good");
}
else {
  console.log("pass");
}

Switch statement


  switch(expression) {
  case x:
    // code block
    break;
  case y:
    // code block
    break;
  default:
    // code block
}

Example:


let day = 3;
switch (day) {
  case 1:
  console.log("Monday");
  break;

  case 2:
  console.log("Tuesday");
  break;

  case 3: 
  console.log("Wednesday");
  break;

  case 4: 
  console.log("Thursday");
  break;

  default:
  console.log("non-working day");

}

Shorthand for the if else ?

The ? is going to evaluate the condition and set it ti the first value if condition is true, to the second if it is false 


let isMember = true;
let price = isMember ? "$10": "$20";
console.log(price)
