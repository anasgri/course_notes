Working with JSON

  • JSON uses key-value pairs and supports different data types
  • JSON iteslf is a string but there are the ways to convert it

Example how can you convert the JSON string into JavaScript Object


let jsonString = '{ "name": "Alice", "age": 30 }';
let user = JSON.parse(jsonString);
console.log(user.name); // "Alice"
console.log(user.age);  // 30

Always use try catchstatement when converting JSON into object.

There is a chance that the string is formatted incorrectly.


let jsonString = '{ "name": "Alice", "age": 30 }';
try {
  let user = JSON.parse(jsonString);
  console.log(user.name);
} catch (error) {
  console.error("Invalid JSON format!", error);
}

Converting from object into the string using JSON.stringify() 


let user = {
name: "Alice",
age: 30,
isMember: true
};
let jsonString = JSON.stringify(user);
console.log(jsonString);
// Output: {"name":"Alice","age":30,"isMember":true}

Use the second parameter of JSON.stringify() to format JSON.


let user = {
  name: "Alice",
  age: 30,
  isMember: true
};
let formattedJSON = JSON.stringify(user, null, 2);
console.log(formattedJSON);
  • null as the second parameter maintains all properties.
  • 2 specifies the number of spaces for indentation

In JSON.stringify(value, replacer, space), the second argument (replacer) controls which properties get included and/or how values are transformed. Instead of null, you can pass: 


let user = { name: "Alice", age: 30, isMember: true, password: "secret" };

let json = JSON.stringify(user, ["name", "age"], 2);
console.log(json);
// {
//   "name": "Alice",
//   "age": 30
// }

Using fetch() to send data to the post request


let user = {
  name: 'Alice',
  email: 'alice@example.com'
}

fetch('https://api.example.com/addUser', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify(user),
})
  .then((response) => response.json())
  .then((data) => console.log('User added:', data))
  .catch((error) => console.error('Error:', error))
