JavaScript Objects

The JavaScript object is the equivalent of the python dictionary


        let person = {
            name: "Alice", 
            age: 25,
            isStudent: true
        };
        // the values can be accesed, either using dot notation or the bracket notation. 
    console.log(person.name);
    console.log(person["age"])

Addind the properties can be done just by dot notation.


        let car = {
        brand: "Toyota",
        model: "Corolla"
            }
        car.year = 2022;

You can also delete properies by using the below shown way


let car = {
brand: "Toyota",
model: "Corolla"}

delete car.brand;
console.log(car)

How to store the function in the object


const person = {
name: "Alice",
age: 29,
grades: [10, 10, 9, 9],
greeting: function () {
    console.log("Hello " + this.name + "!");
}
    }
person.greeting();

In the example above to call the person object within the person object itself we use this, so we have this.name instead of person.name

Another more advanced function


const person = {
  name: "Alice",
  age: 29,
  grades: [10, 10, 9, 9],
  birthday: function () {
    this.age += 1;
    console.log(
      "Happy birthday " + this.name + " you are " + this.age + " years old!",
    );
  },
};
person.birthday();

Object methods

Objects can have methods (functions attached to an object). Methods in objects are like buttons on a calculator. Pressing the button (calling the method) triggers a specific function, such as adding or subtracting numbers. 


  let calculator = {
  add: function(a, b) {
    return a + b;
  },
  subtract(a, b) {
    return a - b;
  }
};

console.log(calculator.add(5, 3));      // 8
console.log(calculator.subtract(10, 4)); // 6
