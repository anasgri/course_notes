Css variables and custom properties

The css varaibles are the way how youn can save the information that yoiu reuse in the css

Below is the example:


        :root {
            --primary-color: #3498db;
            --secondsry-color: #2cbd00;
            --font-size: 16px;
        }

Using variable names


        h1 { 
            color: var(--primary-color, #0000); /*Using fallback in case if variable is inaccessible */
            font-size : var(--font-size);
        }

Variable scoping

Variables can be scoped to individual elements. The local varaible overrides the grobal one 


        .card {
            --card-padding: 2rem;
            padding: var(--card-padding)
        }

Importantly, it has no effect outside the card class.

Rules for variables

  • use :root t for global variables.
  • Organize variables by type (colors, fonts, spacing).
  • Use semantic names (e.g., --primary-color, not --blue)
  • Avoid too many variables; keep it manageable.
  • Use variables for reusable values (padding, margin).
