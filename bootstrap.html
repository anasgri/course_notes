Installing bootstrap

Option 1

  1. Go to https://getbootstrap.com/
  2. Scroll down to CDN and copy it.

CDN is below:

This link needs to be placed in the heaf section


  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" 
  rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">

The lnk below needs to be placed below the body section.


      <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" 
      integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" 
      crossorigin="anonymous"></script>

The javascript script can be also added to the beginning of the file if you add defer 


      <script defer src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" 
      integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" 
      crossorigin="anonymous"></script>

or put it before your body tag without the defer


  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" 
  integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI"

Bootstrap typography

Bootstrap can be used to change the properties of the text by assigning the text, just by using the pre-made classes. 


<h1 class = "h2">Heading 1 that is going to appear as heading 2</h1>
<h2 class = "mark">Marked heading 2</h2>
<h2 class = "em">Emphasized text</h2>
<h2 class = "text-primary">Colored text</h2>

Bootstrap layout

Breakpoint Class infix Dimensions
Extra small (none) <576px
Small sm ≥576px
Medium md ≥768px
Large lg ≥992px
Extra large xl ≥1200px
Extra extra large xxl ≥1400px 

      <div class="container">
  <div class="row">
    <!-- Full width on mobile, half width on medium+, one-third on large+ -->
    <div class="col-12 col-md-6 col-lg-4">
      Column content
    </div>
    <div class="col-12 col-md-6 col-lg-4">
      Column content
    </div>
    <div class="col-12 col-md-6 col-lg-4">
      Column content
    </div>
  </div>
</div>

In this example:

  • On screens smaller than 768px (mobile), each column takes the full width (col-12)
  • On screens 768px and up (tablets), each column takes half width (col-md-6)
  • On screens 992px and up (desktops), each column takes one-third width (col-lg-4)

Bootstrap uses a 12-column grid to create layouts. It’s based on rows and columns.

  • .container: wraps your content.
  • .row: creates a horizontal group.
  • .col: divides space equally within the row

      <div class="container">
  <div class="row">
    <div class="col-4">Column 1</div>
    <div class="col-4">Column 2</div>
    <div class="col-4">Column 3</div>
  </div>
  <div class="row">
    <div class="col-6">Column 1</div>
    <div class="col-6">Column 2</div>
  </div>
  <div class="row">
    <div class="col-3">Column 1</div>
    <div class="col-3">Column 2</div>
    <div class="col-3">Column 3</div>
    <div class="col-3">Column 4</div>
  </div>
</div>

Bootstrap uses the pre-made classes. The class name eg col-4 multiplied by the number of these rows should add up to 12. 


<div class="col-6">Half width</div>
<div class="col-3">Quarter width</div>

Bootstrap allows you to make different layouts at different screen sizes.

  • col-md-6: half width on medium screens (≥768px)
  • col-lg-4: one-third width on large screens (≥992px)

Below is the example of the responsive column that will be half on the small screens, but is going to shtrink to quater on larger screens. 


<div class="col-md-6 col-lg-4">Responsive column</div>

container-fluid - class that creates the container without margins.

When using the bootstrap, the columns need to be nested inside the rows.

Bootstrap components

  • Built-in grid system for layouts.
  • Extensive documentation and community support
