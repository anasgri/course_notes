An API is a set of rules that allows one application to communicate with another

Web APIs: Allow communication between client-side applications and server-side resources.

Data Exchange: Uses formats like JSON or XML. These are the formats of the data that are exchanged.

This process follows the Request/Response Model: Client sends a request, and the server responds with data.

Example if the JSON format


{
  "name": "Alice",
  "age": 30,
  "city": "New York"
}

Example if the XML format


<user>
  <name>Alice</name>
  <age>30</age>
  <city>New York</city>
</user>

AJAX

AJAX is a technique used to send and receive data asynchronously without refreshing the page.

It is basically asynchronous JavaScript

  • Asynchronous Communication: Allows background data exchange.
  • Uses XMLHttpRequest or Fetch API: Sends and retrieves data.
  • Improves User Experience: Dynamically updates the webpage without a full reload.

How AJAX works

  1. User Action: An event (e.g., button click) triggers a request.
  2. Request Sent: JavaScript sends a request to the server.
  3. Server Processes: The server processes the request and returns data.
  4. Response Received: JavaScript processes the returned data.
  5. Page Updated: Content is dynamically updated without reloading.
