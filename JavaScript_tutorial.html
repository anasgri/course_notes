JavaScript tutorial

Declaration of the variables in JavaScript


    let name = "john";
    let age = 25;
  • let creates a variable that can be reassigned.
  • const creates a variable that cannot be reassigned.
  • var (older syntax) should generally be avoided

Datatypes in JavaScript

  • String – Text, surrounded by quotes
  • Number – Any numeric value
  • Boolean – True or false values
  • Object – Collection of key-value pairs
  • Array – Ordered list of items
  • Undefined – Variable declared but not assigned
  • Null – Represents an empty or non-existent value

        // String
let name = "Alice";

// Number
let score = 95;

// Boolean
let isOnline = true;

// Object
let person = {
  name: "John",
  age: 30
};

// Array
let colors = ["red", "blue", "green"];

// Undefined
let x;

// Null
let emptyValue = null;

Checking the type of the certain variable


console.log(typeof name);      // "string"
console.log(typeof score);     // "number"
console.log(typeof isOnline);  // "boolean"
  • Variable names are case-sensitive.
  • They must begin with a letter, $, or _.
  • Cannot be a reserved JavaScript keyword
  • Use camel-case

It is possible to assign multiple variables at once
