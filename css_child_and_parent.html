More complex css selectors

element > child_element


<ul class="breadcrumb">
<li>Home</li>              <!-- matches -->
<li>Products
<ul>
<li>Shoes</li>         <!-- does NOT match (grandchild) -->
</ul>
</li>
</ul>


.breadcrumb > li {
display: inline;
}

The > is the child combinator. It means "select only direct children," not any descendant further down the tree.

So .breadcrumb > li matches every <li> that sits directly inside an element with the class breadcrumb, and sets those to display: inline (so they line up horizontally instead of stacking as list items).

Selector Matches
A B any B inside A, at any depth
A > B only B that is a direct child of A
A + B the B immediately after A (sibling)
A ~ B all B siblings that come after A
