Destructuring

In the example below the new list is assigned to be equal to fruits, now if we call console.log(first); it gives apple. 


const fruits = ["apple", "banana", "cherry"];
const [first, second, third] = fruits;
console.log(first);  // "apple"
console.log(second); // "banana"

Below is the example how can you assigns object properties to variables with matching names. 


const user = {
  name: "Alice",
  age: 25,
  city: "New York"
};
const { name, age, city } = user;
console.log(name); // "Alice"
console.log(age);  // 25

Destructuring can be used for nested arrays and objects


const person = {
  name: "John",
  address: {
    city: "London",
    country: "UK"
  }
};
const { name, address: { city, country } } = person;
console.log(city); // "London"

The spread operator (...)

This is the way how to combine the two arrays.


const numbers = [1, 2, 3];
const newNumbers = [...numbers, 4, 5];
console.log(newNumbers); // [1, 2, 3, 4, 5]

More examples how you can use spread operators to merge arrays and opbjects 


    // Merge arrays
const arr1 = [1, 2];
const arr2 = [3, 4];
const mergedArray = [...arr1, ...arr2];
console.log(mergedArray);

// Merge objects
const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3, d: 4 };
const mergedObject = { ...obj1, ...obj2 };
console.log(mergedObject);

Rest operator for unpacking the array

The rest operator (...) collects remaining elements into an array or object. 


const [first, second, ...rest] = [10, 20, 30, 40, 50];
console.log(first);  // 10
console.log(second); // 20
console.log(rest);   // [30, 40, 50]
