Grid Layout


.container {
    display: grid; /* activates the grid layout */
    grid-template-columns: repeat(3, 1fr); /* defines the grid, in this case repeats 3 times 1 fraction */
    gap : 20px;   
}

Another example


.grid-container {
    display: grid; /* activates the grid layout */
    grid-template-columns: 200px 1fr;
    grid-template-rows: auto 100px;
    gap : 20px;   
}

Columns

First column will have the fixed width of 200px.

Second column: 1fr takes up the remaining space in the grid container (total width minus 200px minus any gap).

If the container is 1000px wide, the gap is 20px, the second column gets 1000 - 200 - 20 = 780px.

Rows

auto means the row's height is sized based on its content — specifically, it grows to fit the tallest/largest content placed in that row (subject to the content's own min/max constraints). It's not a fixed value; it expands or shrinks depending on what you put inside it.

The second row will be exactly 100px.

Thus this container is going to be 2x2 layout.

Adding items to the grid

Below is the example how the item is getting added to the grid.

1/3 means span from column 1 to column 3


.item1 {
    grid-column: 1/3;
    grid-row: 1/3;
}
