Skeuomorphic design of the buttons

This section is about creating nice Skeuomorphic buttons, skeumorphic means that it looks like the real life object

The general syntaxis for the shaddow is shown below


        box-shadow: [inset] <offset-x> <offset-y> <blur-radius> <spread-radius> <color>

inset paremeter

Without inset, the shadow is drawn outside the box. With it, the shadow is drawn inside, and the offset direction effectively flips (a positive y-offset lights up the top edge, not the bottom).

box-shadow accepts a comma-separated list of shadows, so you can stack as many as you like on one element.

below is the example with three:


 box-shadow:
  0px 2px 2px rgba(63, 63, 63, 0.1),          /* 1 */
  0px -2px 2px rgba(255, 255, 255, 0.25) inset, /* 2 */
  0 2px 2px rgba(255, 255, 255, 0.4) inset;     /* 3 */

1. Outer drop shadow

0px 2px 2px rgba(63,63,63,0.1): a faint gray shadow pushed 2px down, outside the element. This makes the element look slightly lifted off the page.

2. Inner shadow at the bottom edge

0px -2px 2px rgba(255,255,255,0.25) inset: the inset keyword draws the shadow inside the box. With a negative y-offset (-2px), the shadow shifts upward, so the light glow shows along the bottom inner edge.

3. Inner highlight at the top edge

0px 2px 2px rgba(255,255,255,0.4) inset: also inset, but with a positive y-offset (+2px), so the shadow shifts downward and the light glow appears along the top inner edge. It's brighter (0.4 vs 0.25), which mimics light hitting the top of a surface.

Specifying the button background to achive the skeumorphic design

In the example below we use the linear gradient and the corresponding border color 


        background: #0ebc0e;
        background: linear-gradient(#0ebc0e, #0c960c);
        border-color: #064f06;

The full example styling of the button


        button {
        height: 50px;
        width: 200px;
        cursor: pointer;
        font-weight: 600;
        font-size: 15px;
        display: block;
        margin: 20px 0px;
      }

      .skeuomorphic {
        border: 2px solid #0c960c;
        border-radius: 5px;
        color: #f8f8f8;
        box-shadow:
          0px 2px 2px rgba(0, 0, 0, 0.2),
          0px -2px 2px rgba(255, 255, 255, 0.5) inset,
          0 2px 2px rgba(255, 255, 255, 0.8) inset;
        background: linear-gradient(#1d1, #0ebc0e);
        text-shadow: 0 -2px #0c960c;
      }

      .skeuomorphic:hover {
        box-shadow:
          0px 2px 2px rgba(0, 0, 0, 0.1),
          0px -2px 2px rgba(255, 255, 255, 0.25) inset,
          0 2px 2px rgba(255, 255, 255, 0.4) inset;
        background: #0ebc0e;
        background: linear-gradient(#0ebc0e, #0c960c);
        border-color: #064f06;
      }

      .skeuomorphic:active {
        margin-top: 2px;
        margin-bottom: -2px;
        box-shadow:
          0px 2px 2px rgba(63, 63, 63, 0.1),
          0px -2px 2px rgba(255, 255, 255, 0.25) inset,
          0 2px 2px rgba(255, 255, 255, 0.4) inset;
        background: #0c960c;
        background: linear-gradient(#0c960c, #0ebc0e);
      }
