JavaScript debugging

Debugging is the process of finding and fixing errors or bugs in your code.

  • Syntax Errors: Mistakes in the structure of the code.
  • Runtime Errors: Errors that occur while the script is running.
  • Logical Errors: Code that runs but produces incorrect results

The easiest way how to do the debugging is a console.log()

There are other debugging methods

  • console.log() – Displays standard messages.
  • console.error() – Displays error messages.
  • console.warn() – Displays warnings.
  • console.table() – Displays tabular data.
  • console.group() – Groups related messages together

debugger statement poses the code execution like a breakpoint. 


function calculate(a, b) {
  let result = a + b;
  debugger;
  return result;
}
calculate(5, 3);

Catching error using the try catch statement


try {
  // Code that may cause an error
} catch (error) {
  // Code to handle the error
}

Optional finally block

The finally block executes after the try and catch blocks, whether an error occurred or not. It is commonly used for cleanup tasks (e.g., closing files, stopping loaders, etc.). 


    try {
  // Code that may cause an error
} catch (error) {
  // Code to handle the error
} finally {
  // Code that always runs, no matter what
}
