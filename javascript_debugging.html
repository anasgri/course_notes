JavaScript debugging

Debugging is the process of finding and fixing errors or bugs in your code.

  • Syntax Errors: Mistakes in the structure of the code.
  • Runtime Errors: Errors that occur while the script is running.
  • Logical Errors: Code that runs but produces incorrect results

The easiest way how to do the debugging is a console.log()

There are other debugging methods

  • console.log() – Displays standard messages.
  • console.error() – Displays error messages.
  • console.warn() – Displays warnings.
  • console.table() – Displays tabular data.
  • console.group() – Groups related messages together

debugger statement poses the code execution like a breakpoint. 


function calculate(a, b) {
  let result = a + b;
  debugger;
  return result;
}
calculate(5, 3);

Catching error using the try catch statement


try {
  // Code that may cause an error
} catch (error) {
  // Code to handle the error
}

Optional finally block

The finally block executes after the try and catch blocks, whether an error occurred or not. It is commonly used for cleanup tasks (e.g., closing files, stopping loaders, etc.). 


    try {
  // Code that may cause an error
} catch (error) {
  // Code to handle the error
} finally {
  // Code that always runs, no matter what
}

Another example

In JavaScript, we use try...catch statement to anticipate and handle errors. Take a look at the following example: 

try {
  throw Error('This error will get caught');
} catch (e) {
  console.log(e);
}
// Prints: This error will get caught

console.log('The thrown error that was caught in the try...catch statement!');
// Prints: 'The thrown error that was caught in the try...catch statement!'

Now, let’s break down what happened in the try...catch statement above:

  • We have code that follows try inside curly braces {} known as the try block.
  • Inside the try block, we insert code that we anticipate might throw an error.
  • Since we want to see what happens if an error is thrown in the try block, we throw an error with the message 'This error will get caught'.
  • Following the try block is the catch statement, which accepts the thrown error from the try block. The e represents the thrown error.
  • The code within the curly braces that follows catch(e) is known as the catch block and executes to handle an error when one is thrown.
  • Since the error is caught, our console.log() after the try...catch statement prints 'The thrown error that was caught in the try...catch statement!'.
